# Autonomous Coder AI

Автономная самообучающаяся нейросеть на Node.js для генерации и автодополнения кода на Python и JavaScript. Система в фоновом режиме осуществляет сбор открытого исходного кода из публичных репозиториев GitHub, валидирует синтаксис через AST и проводит непрерывное дообучение модели с сохранением чекпоинтов на диск.

---

## Архитектура и возможности

- **Авторегрессионная нейросеть (Char-RNN)**: полная реализация на чистом JavaScript без внешних ML-библиотек. Поддерживает прямой проход, расчет функции потерь (Cross-Entropy), обратное распространение ошибки во времени (BPTT) и адаптивный градиентный спуск (Adagrad).
- **Языковое обусловливание (Language Conditioning)**: входные данные маркируются служебными токенами `<|py|>` и `<|js|>`, что позволяет одной модели разделять контексты и правила синтаксиса Python и JavaScript.
- **Синтаксическая валидация (AST-фильтр)**: предварительный синтаксический анализ входящего кода. JavaScript проверяется через парсер с поддержкой ES-модулей, Python — через модуль `ast`. Невалидный или поврежденный код автоматически отсекается до передачи в модель.
- **Фоновый сборщик GitHub**: модуль периодического опроса GitHub Search и Trees API, загружающий актуальные файлы по критериям популярности репозиториев.
- **Персистентность и чекпоинты**: автоматическое сохранение весов, словаря и оптимизатора в файл `model_checkpoint.json` и локальный архив датасета в каталог `dataset/`. При перезапуске прогресс восстанавливается автоматически.
- **Веб-дашборд и REST API**: встроенный интерфейс для мониторинга метрик, ручного тестирования генерации и управления краулером.
